🎬 Movie Catalog

Интерактивная платформа поиска фильмов и актёров

React + TypeScript + TMDB API + Firebase

📋 Проблема

  • Как найти общие фильмы двух актёров?
  • Какие актёры играли в обоих твоих любимых фильмах?
  • Обычный поиск не показывает эти связи

✨ Интерактивный граф связей

  • Введи двух актёров → покажет общие фильмы
  • Введи два фильма → найдёт общих актёров
  • Кликни на любой узел → откроются детали

🚀 Основные возможности

  • 📊 Динамический граф с react-force-graph
  • ⭐ Избранное с Redux управлением
  • 💬 Отзывы и рейтинги на Firebase
  • 🔍 Умный поиск с автодополнением

⚙️ Технологический стек

Frontend

React 18, TypeScript, Redux, React Router, Vite

Backend & Данные

TMDB API, Firebase Firestore, Визуализация графов

👥 Поиск по актёрам

  • 1. Введи имя актёра (например, Leonardo DiCaprio)
  • 2. Добавь второго актёра (Tom Hardy)
  • 3. Граф мгновенно покажет общие фильмы
  • 4. Кликни на фильм → просмотри отзывы

🎞️ Поиск по фильмам

  • Найди фильм → нажми на кнопку граф (🔗)
  • Сразу увидишь всех актёров фильма
  • Изучай взаимосвязи актёров внутри фильма

🏗️ Архитектурные решения

  • Redux для глобального состояния избранного
  • Firebase Firestore для отзывов пользователей
  • Кэширование API и автодополнение
  • Force-graph для визуализации связей

🧩 Основные компоненты

  • MovieCard: карточка фильма с избранным
  • GraphVisualization: интерактивный граф
  • SearchAutocomplete: поиск с предложениями
  • ReviewPanel: отзывы на Firebase

💡 Почему это важно

Графы превращают статичные данные в динамические сети. Находи скрытые связи между любимыми актёрами и фильмами в реальном времени.
